# Fonts

All fonts are embedded into the binary.

- Inter (Regular, Bold) - SIL Open Font License 1.1, see `Inter-LICENSE`
- JetBrains Mono (Regular, Bold) - SIL Open Font License 1.1
- Space Grotesk Bold - SIL Open Font License 1.1. Static instance (wght=700) generated from the variable font with `fonttools varLib.instancer`, since the text renderer does not select variable font instances.
- Lucide icons - ISC license, shipped by the `lucide-icons` crate

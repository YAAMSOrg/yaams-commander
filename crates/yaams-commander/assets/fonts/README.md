# Fonts

All fonts are embedded into the binary. Static files only - the text renderer does not select variable font instances.

- IBM Plex Sans (Regular, SemiBold) - body text and controls
- IBM Plex Sans Condensed (SemiBold, Bold) - captions, table headers, headings, wordmark
- IBM Plex Mono (Regular, Bold) - codes, times, IDs and figures

IBM Plex is licensed under the SIL Open Font License 1.1, see `IBMPlex-LICENSE`. Static builds from the IBM Plex and Google Fonts repositories.

- Lucide icons - ISC license, shipped by the `lucide-icons` crate
